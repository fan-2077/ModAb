# ModAb 抗体科研工作台

ModAb 将研究讨论、任务委托、计算执行、结构测量和结果追问关联在同一个工作台中。
本交付包按 MIT 许可证提供自研源代码与配套文档，并包含一个真实完成的原始 AT8/Tau 三状态案例；第三方资源适用各自条款。
参赛报告中的结果来自本包保留的数据；离线查看不会发起科学计算。

新增的姿态诊断与条件建模已经由 Agent 实际调用：发现不同种子下接触排序反转后，检查原子与编号，区分肽段自身形状和相对抗体的姿态，再比较软模板与明确骨架约束。全部 10 个结构和运行记录保存在 [姿态校准案例](case/pose-calibration/diagnosis.json)。

## 1. 无网络查看真实案例

需要 Python 3.11 或更新版本。查看器仅使用 Python 标准库，不需要 GPU 或 API。

```powershell
python review_server.py
```

浏览器打开 http://127.0.0.1:3081/review.html 。页面可切换指标、旋转 Cα 主链、下载结构与原始数值，并查看实际流程及对照结果。按 Ctrl+C 停止。
仅在本机回环地址提供文件，不作为公众服务部署。页面已明确标记“已完成案例”，没有模拟的新任务或伪造聊天。

## 2. 从保留坐标重新测量

建议在新建虚拟环境中执行；已在 Windows / Python 3.14 下核验。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-review.txt
.venv\Scripts\python verify_case.py
```

通过条件：3 个预测坐标和参考坐标的 SHA-256 一致，所有几何指标与 results.json 的最大绝对差小于 1e-8。
该检查重算已保留坐标，不重新运行 Boltz。NumPy 2.4.0 需要兼容的 Python 版本；完整重测建议 Python 3.11–3.14。

新增姿态案例同样可以直接重测：

```powershell
.venv\Scripts\python verify_pose_case.py
```

它核对全部 10 个坐标文件，并重算形状、位置、转角、磷酸原子完整性以及 4、4.5、5、6 Å 四种阈值的接触数。预期输出 `status: PASS`、`structures: 10`。

## 3. 自研代码和在线工作台

- `backend/modab/autonomy/`：任务、状态机、预算、监督执行、本地/SSH 适配、报告事实约束和工作台接口。
- `backend/modab/`：项目数据、工具注册、生成与研究桥接。
- `dsh/workbench/`：DSH 原生对话扩展、研究面板、结构查看和本地配置生成器。
- `case/`：3 个预测结构、处理后的参考、完整读数、候选原始几何摘要及固定流程对照。
- `backend/modab/tests/`：工程单元测试；其中依赖外部执行环境的检查应按所需条件运行。

在线模式使用 DSH 0.2.1-rc.3、Node.js、Python、独立任务服务、DeepSeek API 与已配置的 SSH 科学计算环境。Boltz 2.2.1 预测环境、模型权重和 MSA 服务需要另行准备。它不是离线查看器的启动依赖。
`dsh/workbench/launch.ps1` 从当前目录定位文件；`MODAB_PYTHON` 和 `MODAB_CONFIG` 可指定解释器及任务服务配置，`-Port` 可调整工作台端口。
生成器把模板变量替换到 `runtime/workbench-v1/local.patch.yml`。模板不包含本机绝对路径；不要把模板直接作为 DSH patch 传入。

完整在线部署还需要绑定任务配置、科学资源和模型账户。当前包的已验证复现范围是离线浏览与坐标重测，未宣称任意新机器的一键在线预测。宿主专属的历史安装/修复脚本和既有运行数据库未纳入分发；自研运行代码保留。

## 4. 科学案例

原始 AT8 Fv + Tau195–214（20 残基），未磷酸化、pS202/pT205、pS202/pT205/pS208 三状态。
本任务各状态 1 个样本、seed 42。200 采样步、3 次 recycling、1 diffusion sample、启用 potentials、server MSA。
抗体 225 个 Cα 对齐后，对共享 Tau202–209 的 8 个 Cα 计算坐标偏差；接触阈值 4.5 Å，近接触阈值 4 Å。
Tau 坐标偏差分别 8.40、6.55、6.14 Å；总残基对接触 48、55、47；磷酸参与接触 0、10、0。
位置偏差同时含肽段形状和相对位置差别。接触计数、结构置信度不是亲和力测量。
新增诊断已将这两种变化分开：三磷酸化 seed 7/42 的肽段独立对齐偏差仅 0.51/0.84 Å，而保持抗体对齐时为 5.24/6.14 Å，主要问题因此指向结合姿态。工具实现位于 `backend/modab/autonomy/pose_diagnostics.py`，并接入已有工具注册、预算、预测和报告流程。
四个生成候选均保留在分母中，本次独立三状态预测覆盖 0/4；candidate-04 原始结构有一处小于 2 Å 的跨链重原子近接触。
历史重复的 seed 42 坐标不能叠加为新的独立样本；历史 5 Å 接触数不能与本任务 4.5 Å 接触数直接混合。
